# Privacy Policy for Deep Sleep Learning Automation

**Last updated: November 19, 2026**

This Privacy Policy describes how the personal automation tool "Deep Sleep Learning Automation" collects, uses, and protects information.

### 1. Data Collection & Usage
- **Google YouTube API**: This application uses the YouTube Data API v3 strictly to upload, schedule, and update metadata for educational video content owned by the channel administrator.
- **Personal Information**: No user data, personal identifying information, or viewer analytics are sold, shared, or transferred to third parties.

### 2. Token Storage & Security
- OAuth tokens (`token.json`) and client secrets (`client_secrets.json`) are stored locally on the administrator's private workstation and within private GitHub repository secrets for continuous automated publishing.
- Tokens are never exposed publicly or sent to external servers.

### 3. Google API Services User Data Policy
This application adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
